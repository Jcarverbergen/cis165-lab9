One Decision
One important decision I made was using a Boolean variable called hasData to keep track of whether the user entered any valid numbers. I learned that initializing the smallest and largest variables to zero could cause incorrect results, especially when all the numbers are negative or positive. Instead, I initialized both variables using the first valid number entered. I kept this approach because it makes the program work correctly with different inputs.
